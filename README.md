# Vaanora

### Martian Surface Intelligence & Marswalk Planner

Vaanora is an interactive web-based prototype developed for the
2026 NASA Space Apps Challenge.

## Challenge

Interplanetary Survival Guide: Martian Map

## What Vaanora Does

Vaanora integrates Martian surface information into a single
mission-planning interface to help future explorers evaluate
potential Marswalk routes.

## Key Features

- Interactive Mars map
- Terrain visualization
- Science targets
- Potential hazards
- Rover/mission locations
- Marswalk route visualization
- Route statistics
- NASA data attribution

## NASA Data

Vaanora uses NASA resources including Martian topography,
surface imagery, and planetary mapping resources.
